# Danske historiske geodata 0.4.3
Install ZIP in QGIS Plugin Manager. Browse the categorized catalogue and select Hent og tilføj til kort. Public Zenodo records and a shared Dropbox folder are supported. Files are cached in the active QGIS profile under historical_geodata, outside the plugin directory. Existing caches are retained. New dataset groups are inserted at the top of the layer tree. The Dropbox landbebyggelser archive is identified by a unique filename prefix; its complete upstream filename was not available. Consult original sources for licences and attribution. Plugin code GPL-2.0-or-later. Public plugin repository metadata must be finalized before submission.
